# Linux File & Directory Permission Management

## Project Overview
This project demonstrates Linux file and directory permission management by creating department folders, assigning ownership, and configuring permissions.

## Project Scenario
ABC Technologies has three departments:
- Developers
- Managers
- Shared

As a Linux Administrator, I:
- Created department directories.
- Assigned group ownership.
- Configured secure permissions.
- Created sample files.
- Verified permissions and ownership.

## Commands Used
- mkdir
- touch
- chmod
- chown
- chgrp
- ls

## Tools Used
- AlmaLinux
- VMware Workstation Pro

- Linux File Permissions
- Directory Management
