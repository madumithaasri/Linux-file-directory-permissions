# Linux File & Directory Permission Management

## Objective
To learn how to manage Linux file and directory permissions using real-world administration tasks.

## Tasks Performed
- Created company directories.
- Created department directories.
- Created a managers group.
- Changed group ownership.
- Applied directory permissions using chmod.
- Created files.
- Changed file ownership using chown.
- Verified ownership and permissions.

## Environment
- AlmaLinux
- VMware Workstation Pro

## Skills Gained
- File Permissions
- Directory Permissions
- Ownership Management
- Linux Administration
